# Choose the representation from the relationship

Start with the reader's question and the supplied material. Identify which relationships need to be perceived together and what operation, if any, would help the reader investigate them. Choose only the representations needed to expose those relationships. No document category requires a section sequence or set of components.

Preserve the meaning carried by position, order, alignment, grouping and scale. A visual arrangement should express the actual relationship, not merely group related nouns into boxes. Label connections with what passes between or acts on the connected parts. Comparisons need a common basis, consistent units and explicit conditions. Sequence alone does not establish causation.

Keep evidence close to the claims it supports. Distinguish observation, interpretation, uncertainty and proposed behavior. A quotation should retain enough context to assess it; an assistant's account of its own behavior is not independent verification. Use realistic cases when they clarify a mechanism, without presenting illustrative material as observed fact.

Interaction is justified by what the reader can learn or do through it. Keep a useful initial state and make the consequences of a change visible. Preserve context across states. If an input changes assumptions, update dependent conclusions or make their scope explicit. If an operation affects only part of the page, do not suggest it changed the whole answer.

Do not hide the main answer or essential qualifications behind hover or sequential clicking. Supplementary detail can be disclosed when needed. A static explanation is complete when interaction would not improve the reader's task.
